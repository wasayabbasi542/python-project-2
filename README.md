# Project 2 - Expense Tracker
This is a simple Expense Tracker program made in Python.

The program lets the user:
- Add expenses
- See the total expense
- Stop by typing "quit"

 How to Run

1. Open the project in VS Code.
2. Run the Python file.
3. Enter your expenses one by one.
4. Type `quit` to finish.
5. The program will show the total expense.

## Example

Enter expense: 100
Enter expense: 50
Enter expense: 20
Enter expense: quit

Total Expense: 170
